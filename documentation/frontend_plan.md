# 📋 الخطة التطويرية للواجهة الأمامية (Frontend)

هذه الخطة توضح الخطوات والمهمات اللازمة لتطوير وتوصيل الواجهة الأمامية مع الباك إند. كل مهمة رئيسية تحتوي على مجموعة من المهمات الفرعية مع مربعات اختيار (checkboxes) لتتبع التقدم.

---

### المرحلة الأولى: الإعداد والمكونات الأساسية 뼈
- [x] **📝 إدارة المشاريع (Project Management):**
    - [x] ▫️ جلب وعرض قائمة المشاريع الحالية من الباك إند (`GET /api/v1/projects`).
    - [x] ▫️ السماح للمستخدم باختيار مشروع للعمل عليه وتخزين `project_id`.
    - [x] ▫️ تعديل واجهة "مشروع جديد" لإنشاء/تبديل المشاريع عبر `ID`.

- [x] **🗂️ إدارة الملفات والبيانات (File & Data Management):**
    - [x] ▫️ بناء واجهة لرفع الملفات (`.pdf`, `.txt`) للمشروع المختار (`POST /api/v1/data/upload/{project_id}`).
    - [x] ▫️ عرض الملفات التي تم رفعها في المشروع الحالي.
    - [x] ▫️ إضافة زر لبدء عملية معالجة الملفات وتقسيمها (`POST /api/v1/data/process/{project_id}`).
    - [x] ▫️ عرض رسائل للمستخدم توضح نجاح أو فشل عمليات الرفع والمعالجة.

---

### المرحلة الثانية: ربط خط أنابيب RAG 🧠
- [x] **⚡ فهرسة البيانات (Indexing):**
    - [x] ▫️ إضافة زر "بناء الفهرس" (Build Index) للمشروع المختار (`POST /api/v1/nlp/index/push/{project_id}`).
    - [x] ▫️ عرض مؤشر تحميل أو شريط تقدم أثناء عملية الفهرسة.
    - [x] ▫️ عرض معلومات وحالة الفهرس للمشروع (`GET /api/v1/nlp/index/info/{project_id}`).

- [x] **💬 واجهة المحادثة والأسئلة (Q&A Interface):**
    - [x] ▫️ تصميم واجهة محادثة (chat) لطرح الأسئلة.
    - [x] ▫️ ربط صندوق الإدخال بنقطة النهاية الخاصة بالإجابة (`POST /api/v1/nlp/index/answer/{project_id}`).
    - [x] ▫️ عرض الإجابة النهائية التي تم إنشاؤها من الباك إند.
    - [x] ▫️ (اختياري) يمكن إضافة قسم لعرض نتائج البحث الأولية (semantic search) من `POST /api/v1/nlp/index/search/{project_id}`.

### المرحلة الثالثة: التحسينات وتجربة المستخدم ✨
- [ ] **🎨 تحسينات الواجهة وتجربة المستخدم (UI/UX Polish):**

    - [ ] ▫️ إضافة حالات تحميل (loading states) ورسائل خطأ واضحة لجميع عمليات الـ API.
    - [ ] ▫️ تحسين تنسيق وتجاوبية (responsiveness) التطبيق على مختلف الشاشات.
- [ ] **⚙️ إدارة الحالة العامة (Global State Management):**
    - [ ] ▫️ استخدام مكتبة لإدارة الحالة (مثل Zustand أو Redux Toolkit) للتحكم في البيانات العامة مثل `project_id` وقائمة الملفات بشكل فعال.
